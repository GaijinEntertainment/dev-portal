Services management

The Services management section allows authorized users to view, configure, and manage services behavior.

To open the services management settings, select the corresponding menu item.

Note

Access to services management settings requires the appropriate permissions.

Matching

The Matching section allows authorized users to view, configure, and manage matchmaking behavior.

  • (1) — switch to enable or disable maintenance mode for matchmaking.

  • (2) — button to open matchmaking actions.

  • (3) — button to reload the current matchmaking data.

Matchmaking actions

The Matchmaking actions section displays a list of available actions for managing matchmaking.

Send Action

  1. Select the required action from the list.

  2. Enter the necessary input data in the text field.

  3. Click Send action.

Reset Action Data

To clear all input fields and restore default values, click the Reset to default button.

Leaderboard actions

The Leaderboard actions section provides actions for managing leaderboards.

To send an action or reset action data, see Matchmaking actions.

Contacts actions

The Contacts actions section provides actions for managing contacts.

To send an action or reset action data, see Matchmaking actions.
